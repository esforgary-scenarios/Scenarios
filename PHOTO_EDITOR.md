# Фоторедактор

## Удаление фона

Кнопка удаления фона использует `@imgly/background-removal` от IMG.LY и ONNX Runtime Web. Модуль подключается только при первом запуске инструмента. Изображение обрабатывается в браузере: API удаления фона на сервере и отправка исходника в IMG.LY не используются. Готовый PNG сохраняется обычным механизмом проекта в личное хранилище Supabase.

При первом запуске браузер загружает модель `isnet_quint8` (около 40 МБ) и файлы WebAssembly с `https://staticimgly.com`. Дальнейшие запуски используют браузерный кэш, пока он доступен. Интерфейс показывает загрузку ресурсов и этап обработки. При ошибке исходный слой остаётся прежним.

Используется CPU/WASM в отдельном модульном Web Worker с OffscreenCanvas, без обязательного WebGPU и без требования заголовков COOP/COEP. ONNX Runtime проверяет доступность SharedArrayBuffer и использует один поток при отсутствии изоляции. Интерфейс продолжает отвечать во время вычислений; кнопка отмены завершает worker. После двух минут простоя worker освобождается. На слабых устройствах обработка может занимать заметное время. Существующая прозрачность слоя сохраняется при применении маски.

## Работа с проектом

Каждый ролик хранит свою композицию. Изображения можно загрузить, вставить из буфера или взять из галереи. Экспорт PNG и «В галерею» создают готовое изображение отдельно от редактируемых слоёв.

Выделите слой на холсте или в списке. Shift выбирает несколько слоёв; перетаскивание строки меняет порядок. У выбранного слоя есть ручки размера и поворота, точные координаты и эффекты справа. Для кривой расставьте узлы, нажмите Enter, затем перемещайте узлы. Двойной щелчок по узлу удаляет его.

Клавиши работают только при фокусе редактора: V — перемещение, C — кадрирование, W — выделение по цвету, B — кисть, E — ластик, G — заливка, I — пипетка, S — штамп, R — размытие, H — резкость, P — кривая. Alt + щелчок задаёт источник штампа. В выделении Shift добавляет область, Alt вычитает. Ctrl+Z / Ctrl+Shift+Z отменяют/повторяют; Ctrl+D дублирует слой. Пиксельные инструменты преобразуют текст и фигуры в изображение; это преобразование можно отменить.

История хранит до 30 действий в открытом редакторе. Текущий проект сохраняется в аккаунте; история сбрасывается при выходе из ролика. Неиспользуемые исходники удаляются после успешного сохранения, когда они уже не нужны ни проекту, ни истории. Галерея и превью также защищают общие файлы от удаления.

Размер холста и слоя — до 4096 пикселей по каждой стороне, до 200 слоёв. Объём — эффект экструзии в 2D. Выделение использует допуск цвета и смежность; удаление фона использует модель выделения объекта. Заливка по контуру нижнего слоя — обтравочная маска; отдельная временная область выделения не сохраняется между сеансами. Внешние изображения должны разрешать CORS, иначе нужно вставить саму картинку или загрузить файл. У SVG нет прямого импорта; поддерживаются PNG, JPG, WebP и GIF (статичный кадр).

Для самостоятельной раздачи моделей нужно скачать пакет данных той же версии, что и установленный `@imgly/background-removal`, и настроить `publicPath`. Нельзя смешивать WASM и JavaScript ONNX Runtime от разных сборок.

## Сторонние компоненты

- [IMG.LY Background Removal](https://github.com/imgly/background-removal-js/tree/main/packages/web) — лицензия [AGPL-3.0](https://github.com/imgly/background-removal-js/blob/main/packages/web/LICENSE.md). При публикации приложения с этой библиотекой нужно соблюдать требования AGPL к доступности соответствующего исходного кода; репозиторий приложения должен содержать исходники и инструкции сборки. Полный текст лицензии поставляется в `node_modules/@imgly/background-removal/LICENSE.md`. IMG.LY также предлагает отдельное лицензирование.
- [ONNX Runtime](https://github.com/microsoft/onnxruntime) — MIT, текст лицензии поставляется с пакетом.
- [Google Fonts CSS2](https://developers.google.com/fonts/docs/css2) — шрифты подключаются по официальной HTTPS-ссылке. Лицензию каждого выбранного шрифта можно посмотреть на странице семейства в Google Fonts. Коллекция хранит название и ссылку, а не копии файлов шрифтов.
